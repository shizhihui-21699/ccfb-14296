# Rowhammer 宿主机防护与仿真组件

针对多租户云主机上的 Rowhammer 攻击（高频激活相邻内存行导致比特翻转，
篡改页表项 / 密钥校验结果）的软件侧防护与量化评估工具。

## 构建与运行

```sh
make        # 需要 C11 编译器 + libm
./rhsim     # 运行三个演示 + 实验矩阵，结果写入 results.csv
```

## 组件

| 文件 | 功能 |
|---|---|
| `src/dram.c` | DRAM 物理地址→(bank,row) 映射模型；**仅用行缓冲冲突时序**推断未公开的映射（先找 row 起始位，再找 bank 位），10000 随机地址验证 |
| `src/alloc.c` | 租户隔离物理行分配器：敏感数据（页表/密钥）独占行，两侧插入 guard row，使攻击者行与受害行的物理距离 ≥ guard+1 |
| `src/spage.c` | 敏感页模型：每比特翻转阈值（对数正态 + 弱单元）；FNV-1a 完整性校验 + shadow 副本修复（scrub） |
| `src/sim.c` | 解析式攻击仿真：干扰累积→阈值翻转→64ms 刷新/scrub 复位；自适应 scrub 间隔；利用窗口建模（翻转后 1ms 内未被修复则攻击成功） |
| `src/main.c` | 演示 + 防护等级×攻击类型实验矩阵 |

## 威胁模型与防御机制

- **攻击**：double-sided（±1 行全速激活）、half-double（±2 行 15% 泄漏）、
  many-sided（绕过 TRR）。
- **隔离**：guard row 吸收干扰。guard=1 挡住 double-sided，guard=2 挡住 half-double。
- **完整性**：scrub 同时起两个作用——恢复受害行电荷（等效局部刷新，阻止翻转累积）
  和检测+修复已发生的翻转。间隔自适应：发现翻转则减半，安静则 ×1.5。
- **关键权衡**：scrub 间隔必须压到攻击者利用窗口（1ms）以下，但每页扫描有
  CPU/带宽成本；guard row 浪费物理内存。
